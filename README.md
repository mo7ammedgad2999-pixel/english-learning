# English Journey — موقع التدريب الشخصي على الإنجليزية

واجهة عربية لتدريب الإنجليزية لمستخدم واحد، دون خادم أو تسجيل دخول أو API. ملف التطبيق الرئيسي `index.html` يتضمن HTML/CSS/JavaScript في ملف واحد.

## التصميم الحالي

- غلاف كحلي داكن، قائمة جانبية، بطاقات فاتحة وملونة، وتخطيط متجاوب.
- معاينة هاتف مبنية بعناصر HTML/CSS على الشاشات العريضة، مع لوحة روابط المستودع وأصول التصميم. تُخفى معاينة الهاتف عند فتح الواجهة على هاتف حقيقي.
- رابط الخلفية الجديد في الكود هو `assets/images/hero-landscape.jpg`. **ملف JPG الفعلي لم يُرفع إلى هذا المستودع بعد**؛ لذلك ستستخدم نسخة GitHub خلفية SVG الاحتياطية حاليًا. تتوفر صورة JPG في حزمة المعاينة المحلية.
- رابط المبتدئين المعتمد: https://www.youtube.com/channel/UCYzEMRKqrh01-tauv7MYyVQ
- المستوى المتوسط: https://www.youtube.com/@EasyEnglishVideos
- YouGlish: https://youglish.com/

## التشغيل المحلي

افتح `index.html` في متصفح حديث بعد تنزيل حزمة المعاينة وفك ضغطها. التسجيل الصوتي قد يتطلب HTTPS أو localhost. روابط YouTube وYouGlish تتطلب الإنترنت. صدّر JSON دوريًا؛ تخزين المتصفح ليس نسخة احتياطية.

## الأقسام

الرئيسية، Shadowing، المفردات، السكريبتات والجمل، التحدث والمواقف، المراجعة، التقدم والإعدادات. راجع `HANDOFF.md` للحالة التفصيلية والنواقص المعروفة.

## حدود مهمة

لا يوجد تصحيح نطق آلي أو ترجمة آلية أو API ذكاء اصطناعي. ملفات التسجيل الصوتي لا تُحفظ تلقائيًا ضمن IndexedDB أو النسخة الاحتياطية. لم يُجر اختبار متصفح شامل لجميع الوظائف؛ لا تعتبر الميزات غير المختبرة مكتملة.
