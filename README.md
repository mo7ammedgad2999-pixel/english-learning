# English Journey — موقع التدريب الشخصي على الإنجليزية

موقع تدريب إنجليزية بواجهة عربية، محلي لمستخدم واحد، بلا حساب أو خادم أو API. ملف التطبيق الرئيسي `index.html` واحد يتضمن HTML/CSS/JavaScript.

## التشغيل
افتح `index.html` في متصفح حديث. YouTube وYouGlish يحتاجان الإنترنت. تسجيل الصوت قد يتطلب HTTPS أو localhost. البيانات تحفظ داخل المتصفح (IndexedDB مع fallback إلى localStorage). صدّر JSON دوريًا؛ تخزين المتصفح ليس نسخة احتياطية.

## الأقسام
- الرئيسية: ملخص الوقت والأهداف اليومية، واجهة بصرية محسنة، وبطاقات ملونة قابلة لإعادة الترتيب بالسحب على الكمبيوتر.
- Shadowing: مستوى التدريب، روابط القنوات، مؤقت، ساعة تناظرية بأرقام، ملاحظات، تشغيل جملة وتسجيل صوتي للمقارنة الذاتية. قناة المبتدئين: https://www.youtube.com/channel/UCYzEMRKqrh01-tauv7MYyVQ
- المفردات: كلمات وأمثلة وبحث وتعديل وحذف ومراجعة متدرجة.
- السكريبتات: قوالب يومية ومشاعر وخطط ومقابلة عمل وجمل شخصية.
- التحدث: يوميات ومؤقت وبنك مواقف لمقابلات العمل والحياة اليومية وأسئلة متابعة وارتجال.
- المراجعة: رحلة التعلم السداسية واختبار أسبوعي ذاتي.
- التقدم والإعدادات: مؤشرات، بداية اليوم، رابط الموقع الشخصي، تصدير/استيراد JSON.

## الحدود
لا يوجد تصحيح نطق آلي أو ترجمة آلية أو API ذكاء اصطناعي. التسجيلات لا تُحفظ تلقائيًا في قاعدة البيانات أو النسخة الاحتياطية في هذه النسخة. يلزم اختبار يدوي على المتصفحات المستهدفة. راجع `HANDOFF.md` للنواقص والأولويات.
